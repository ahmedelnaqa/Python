# FHIR JSON Data Extractor

## 📋 Project Overview

This project provides a comprehensive solution for extracting and analyzing healthcare data from FHIR (Fast Healthcare Interoperability Resources) JSON files. The tool is designed to parse complex medical records, extract patient information, and provide insights into data structure and complexity.

### **Project Need & Purpose**

Healthcare data interoperability is critical for modern medical systems. FHIR has emerged as the standard for exchanging healthcare information electronically. However, working with FHIR JSON files presents several challenges:

- **Complex Nested Structures**: Medical records contain deeply nested data with multiple layers of objects and arrays
- **Standard Compliance**: Data must adhere to HL7 FHIR standards, requiring specific understanding of the structure
- **Data Extraction Difficulty**: Important patient information is often buried within complex paths
- **Inter-resource References**: Different medical records reference each other using UUIDs

This project addresses these challenges by providing:
- A reliable method to extract key patient demographics
- Tools to navigate complex FHIR structures
- Analysis of JSON file complexity for better understanding
- Ready-to-use code examples for common extraction scenarios

## 🛠️ Usage Examples

### **Basic Extraction**
```python
from glom import glom
import json

# Load and extract patient gender
with open('Aaron_testing.json') as f:
    data = json.load(f)
    
gender = glom(data, 'entry.0.resource.gender')
print(f"Patient Gender: {gender}")  # Output: male
```

### **Complex Extraction with Error Handling**
```python
from glom import glom, Coalesce

# Extract race with fallback
race = glom(data, 
    Coalesce(('entry.0.resource.extension', 
              [lambda x: x['url'] == 'us-core-race'],
              'extension',
              [lambda x: x['url'] == 'text'],
              'valueString'), 
             default='Unknown'))
```
